# Отправка в App Store

Всё, что делается в коде, сделано. Ниже — то, что делаете вы.

## 1. Сначала задеплойте сайт

**До** отправки в App Store, иначе ревью упрётся в неработающие ссылки:

```bash
npm run build   # затем обычный деплой на Vercel
```

Проверьте, что открываются:

- `https://oqunet.app/privacy.html` — App Store Connect не примет форму без рабочей ссылки
- `https://oqunet.app/terms.html` — на неё ведёт галочка при регистрации
- `https://oqunet.app/.well-known/apple-app-site-association` — универсальные ссылки

## 2. Создайте приложение в App Store Connect

- Bundle ID: `app.oqunet`
- Название: OquNet
- Основной язык: русский
- Категория: Books (вторая — Social Networking)

## 3. Xcode

```bash
npm run ios
```

1. Таргет **App** → Signing & Capabilities → Team уже стоит (`LUT82RQZTG`)
2. Product → **Archive**
3. Distribute App → App Store Connect → Upload

Версия 1.0, сборка 1. Для каждой следующей загрузки поднимайте `CURRENT_PROJECT_VERSION`.

## 4. Метаданные в App Store Connect

**Скриншоты** — 6.9″ iPhone (1320×2868), минимум 3. Снимите на симуляторе
iPhone 16 Pro Max: ⌘S сохраняет кадр нужного размера.

**Возрастной рейтинг** — в анкете отметьте, что в приложении есть
пользовательский контент и общение между пользователями. Ожидаемый результат
12+ или 17+.

**App Privacy** — отвечайте ровно так, как записано в `PrivacyInfo.xcprivacy`:

| Тип данных | Связан с пользователем | Отслеживание | Назначение |
|---|---|---|---|
| Email | да | нет | App Functionality |
| Имя | да | нет | App Functionality |
| Телефон | да | нет | App Functionality |
| Фото | да | нет | App Functionality |
| User ID | да | нет | App Functionality |
| Пользовательский контент | да | нет | App Functionality |

**Privacy Policy URL**: `https://oqunet.app/privacy.html`

**Экспортное соответствие** — вопроса не будет, ответ уже в Info.plist.

## 5. Заметка для ревьюера

В поле App Review Information → Notes:

> Приложение для обмена бумажными книгами внутри сообществ.
>
> Тестовый аккаунт: <логин> / <пароль>
>
> Модерация пользовательского контента (гайдлайн 1.2):
> • «Пожаловаться» — в меню «⋮» на каждой записи, комментарии и профиле
> • «Заблокировать» — там же; заблокированные исчезают из ленты, комментариев
>   и чатов и не могут писать (запрещено правилами базы, не только интерфейсом)
> • Список блокировок и разблокировка — Настройки → Заблокированные
> • Условия с политикой нулевой терпимости: https://oqunet.app/terms.html
>   принимаются галочкой при регистрации
> • Жалобы рассматриваются в течение 24 часов, контакт: @oqunetapp
>
> Push-уведомления в этой версии выключены.

**Обязательно приложите рабочий тестовый аккаунт.** Без него ревьюер не пройдёт
дальше экрана входа — это самая частая причина отказа после гайдлайна 1.2.

## Что осталось вне этой версии

- **Push-уведомления** — код готов с обеих сторон, но нужен тариф Blaze,
  деплой `functions/`, ключ APNs и capability Push Notifications в Xcode.
  Сейчас `VITE_PUSH_SERVER` заполнен, а capability нет — см. ниже.
- **SHA-1 для Android** — вход через Google на Android не работает без него.
  На iOS не влияет.
