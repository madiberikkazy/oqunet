## Description (4000)

```
OquNet — приложение для обмена бумажными книгами внутри своего круга:
соседей, коллег, однокурсников, книжного клуба.

Прочитанная книга стоит на полке годами. Рядом кто-то ищет именно её.
OquNet соединяет этих двоих.


КАК ЭТО РАБОТАЕТ

Создайте сообщество или вступите в существующее по приглашению. Добавьте
книги, которые готовы отдать почитать. Видите чужую — берёте, договариваетесь
в чате о встрече. При передаче называете код из четырёх цифр, и книга
переходит к вам.

Всё видно: у кого сейчас книга, когда её вернут, где она успела побывать.


ЧТО ВНУТРИ

• Полка сообщества — все книги с обложками, поиск по названию и автору,
  фильтры по жанру и году
• Передача книг — код при встрече, срок возврата, история переходов
• Чаты — договориться о встрече, не выходя из приложения
• Лента — записи участников вашего сообщества
• Таймер чтения — сколько прочитали за день и за неделю, прогресс по страницам
• Совместное чтение — сесть за книгу одновременно с другими
• Профили и подписки — видно, кто что читает


ДЛЯ КОГО

Для книжных клубов, студенческих групп, коллег в офисе, соседей по дому.
Везде, где есть несколько человек и книги, которые незачем держать взаперти.


БЕЗОПАСНОСТЬ

Вступление в сообщество — по приглашению или заявке, которую одобряет
администратор. Номер телефона подтверждается, чтобы человек, приходящий за
книгой, был настоящим.

На любую запись, комментарий или профиль можно пожаловаться — мы рассматриваем
```

## App Review Information → Notes

Обязательно приложите рабочий аккаунт — без него ревьюер не пройдёт дальше
экрана входа. Это вторая по частоте причина отказа.

```
Приложение для обмена бумажными книгами внутри сообществ.

Тестовый аккаунт:
  Email:  ЗАПОЛНИТЬ
  Пароль: ЗАПОЛНИТЬ
Аккаунт уже состоит в сообществе с книгами — так виден весь функционал.

Модерация пользовательского контента (гайдлайн 1.2):
• «Пожаловаться» — в меню «⋮» на каждой записи, комментарии и профиле
• «Заблокировать» — там же. Заблокированные исчезают из ленты, комментариев
  и списка чатов и не могут писать: это запрещено правилами базы данных,
  а не только интерфейсом
• Список блокировок и разблокировка — Настройки → Заблокированные
• Условия использования с политикой нулевой терпимости показываются в
  приложении при регистрации, согласие записывается в профиль
• Жалобы рассматриваются в течение 24 часов, контакт: @oqunetapp

Push-уведомления в этой версии отключены.
```
